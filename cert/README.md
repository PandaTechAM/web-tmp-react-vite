# Local HTTPS Development Setup

The dev server needs HTTPS to handle backend cookies on `react.pandatech.it`. We use [mkcert](https://github.com/FiloSottile/mkcert) to generate locally-trusted certificates that work on **both Windows and Linux**.

The Vite config automatically enables HTTPS when the cert files exist in this directory. No env vars or extra config needed — just follow the setup below.

## Prerequisites

- [mkcert](https://github.com/FiloSottile/mkcert) installed
- Administrator/root access (for hosts file and CA installation)

### Installing mkcert

**Windows** (using [Chocolatey](https://chocolatey.org/) or [Scoop](https://scoop.sh/)):
```bash
choco install mkcert
# or
scoop bucket add extras && scoop install mkcert
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt install libnss3-tools
curl -JLO "https://dl.filippo.io/mkcert/latest?for=linux/amd64"
chmod +x mkcert-v*-linux-amd64
sudo mv mkcert-v*-linux-amd64 /usr/local/bin/mkcert
```

## Setup Steps

### 1. Install the local CA

This makes your OS and browsers trust certificates generated by mkcert:

```bash
mkcert -install
```

### 2. Generate certificates

From the `cert/` directory of this project:

```bash
cd cert
mkcert pandatech.it "*.pandatech.it" localhost 127.0.0.1
```

This creates two files:
- `pandatech.it+3.pem` — certificate
- `pandatech.it+3-key.pem` — private key

### 3. Update hosts file

Add this line to point `react.pandatech.it` to your local machine:

```
127.0.0.1    react.pandatech.it
```

**Windows:** Edit `C:\Windows\System32\drivers\etc\hosts` as Administrator, or run `set_pandatech_host.bat` as Administrator.

**Linux:** Edit `/etc/hosts` with sudo:
```bash
echo "127.0.0.1    react.pandatech.it" | sudo tee -a /etc/hosts
```

### 4. Run the dev server

```bash
npm run dev
```

Vite will automatically start with HTTPS on `https://react.pandatech.it:5173` if the cert files are present.

## How it works

`vite.config.ts` checks if `cert/pandatech.it+3.pem` and `cert/pandatech.it+3-key.pem` exist at startup. If they do, the dev server runs with HTTPS and binds to `react.pandatech.it`. If they don't (e.g., in CI/CD or production builds), the server block is skipped entirely — **this config has zero impact on production**.

## Regenerating certificates

If the certificates expire or you need to regenerate them:

```bash
cd cert
mkcert pandatech.it "*.pandatech.it" localhost 127.0.0.1
```

The mkcert CA is valid for ~10 years. Individual certificates are valid for ~2 years.
